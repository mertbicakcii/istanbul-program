# İstanbul Haftalık Program

İstanbul'da bu hafta ve gelecek hafta oynanacak maçları (futbol, basketbol, voleybol)
ve Biletix etkinliklerini resmi kaynaklardan toplayıp bir web sayfasında yayınlar.
Sayfa her gün 06:00'da (TR) GitHub Actions ile otomatik güncellenir.

Kaynaklar: TFF, UEFA, EuroLeague/EuroCup, TVF, Biletix.
Elle kontrol gerekenler: TBF (BSL), FIBA kupaları, hentbol.

Yerelde çalıştırma: `pip install -r requirements.txt && python istanbul_hafta.py`
